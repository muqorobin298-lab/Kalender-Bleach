Kalender Bleach 📅

Kalender bulanan bertema anime Bleach, dibuat pakai HTML, CSS, dan JavaScript. Catat acara dan tugas di tiap tanggal.

🔗 Pakai di sini: https://muqorobin298-lab.github.io/Kalender-Bleach/

Fitur
Kalender bulanan dengan minggu dimulai hari Senin, tanggal hari ini ditandai
Catatan di setiap tanggal: judul, jam (opsional), dan 4 kategori berwarna (Tugas, Ujian, Acara, Pribadi)
Centang untuk menandai selesai, dan hapus catatan kapan saja
Titik berwarna di kalender menunjukkan tanggal yang punya catatan
Panel Agenda Mendatang berisi 8 catatan terdekat yang belum selesai
Libur nasional dengan tanggal tetap (Tahun Baru, Hari Buruh, Pancasila, Kemerdekaan RI, Natal)
Latar anime berganti mengikuti bulan
Semua catatan tersimpan di browser (localStorage), tanpa server
Nyaman dipakai di laptop maupun HP
Kontrol
Aksi	Cara
Pindah bulan	Tombol ◀ ▶ atau tombol panah ← →
Kembali ke hari ini	Tombol Hari Ini
Lihat atau tambah catatan	Klik tanggal, lalu isi form di panel kanan
Lompat ke tanggal agenda	Klik item di Agenda Mendatang
Catatan

Libur keagamaan yang tanggalnya berubah tiap tahun belum dimasukkan. Catatan hanya tersimpan di browser yang dipakai, jadi tidak terbawa ke perangkat lain.
